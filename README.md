# FFXIV VTT

A Foundry VTT module for recreating features from Final Fantasy XIV.

## Installation

Install the module in Foundry using the manifest URL:

`https://raw.githubusercontent.com/Spacejamming/ffxiv-Foundry/main/module.json`

## Module files

- `module.json` — module manifest
- `scripts/module.js` — main module logic
- `styles/module.css` — module styles

## Development

No build step is required for this initial scaffold. Edit `scripts/module.js` and reload Foundry.
